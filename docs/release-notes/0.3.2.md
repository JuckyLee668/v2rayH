# v2rayH 0.3.2

## Xray 内核更新至 v26.10.31

- vendored xray-core 由 v26.10.29 升级到 **v26.10.31**（上游已移除 v26.10.29 tag）
- 重新应用 OpenHarmony overlay（tun fd 适配 + build tag），
  依赖 protobuf 升至 v1.36.12
- `libxray.a` 已用新版内核重新构建

## 下载测速包大小可自定义

- 新增「设置 → 测速」：下载测速包大小可选 **20 / 50 / 100 / 200 / 500 MB**，持久化保存
- **默认改为 20MB**，降低单次测速的流量与时间成本；大包测稳态更准
- 测速文件 URL 与原生 `maxBytes` 上限随所选大小动态生成；
  Cloudflare 主源失败时按大小回退对应 OVH 文件
- 首页测速确认弹窗与状态文案跟随所选大小显示流量消耗

## 扫码支持添加订阅链接

- 扫二维码得到 `http(s)://` 链接时，弹窗确认后添加为订阅分组并立即更新
- 之前扫出订阅链接会被判为「不是有效的节点链接」；节点分享链接二维码行为不变

## 节点编辑新增「其他信息」

- 编辑节点新增可折叠「其他信息」区，按协议显示高级参数：
  - vless / vmess / trojan：TLS（none / tls / reality）、SNI、指纹、ALPN、
    传输协议（tcp / ws / grpc）与 path / Host、reality 的 pbk / sid / spiderX、
    vless 流控、vmess alterId、允许不安全连接
  - ss：加密方式
  - hy2：SNI、ALPN、混淆（salamander）与混淆密码、端口跳跃（mport）
  - tuic：SNI、ALPN、允许不安全连接
- 固定取值的字段（指纹 / ALPN / 流控 / 加密方式 / 混淆等）为选项而非输入框；
  服务器特定值（SNI / path / pbk 等）保留输入框
- 打开编辑时自动带入当前值，保存后分享链接与双内核配置同步生效

## 其他

- 订阅拉取超时由 15 秒放宽到 60 秒，弱网下更新订阅不易失败
