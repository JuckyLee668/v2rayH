# v2rayH 0.3.3

## 后台保活

- 新增「设置 → 连接 → 后台保活」（默认关闭）：连接期间申请 DATA_TRANSFER
  长时任务，通知栏常驻提醒，防止退至后台后进程被冻结、VPN 断流
- 断开连接或删除通知自动取消长时任务；开关状态持久化
- 模块新增 `KEEP_BACKGROUND_RUNNING` 权限与 `dataTransfer` 后台模式

## 新协议：AnyTLS

- 新增 **AnyTLS** 协议支持，经 sing-box 链式转发承载（与 hy2 / tuic 同架构）
- 分享链接解析 / 生成、订阅导入、节点编辑、测速、故障转移全链路支持

## 新增 http / socks 节点链接解析

- 支持 `http://` / `https://` / `socks://` / `socks5://` 分享链接，
  解析为 http / socks 节点（Xray 出站），可编辑认证用户名 / 密码

## 传输层与高级字段扩展

- Xray 侧传输新增 **mKCP**（headerType 伪装：none / srtp / utp /
  wechat-video / dtls / wireguard + seed 密钥）、**httpupgrade**、**XHTTP**、
  TCP http 伪装，协议与传输自由组合
- VMess 加密方式（scy）、TUIC 拥塞控制（congestion_control，缺省 bbr）、
  mKCP seed 等高级字段经分享链接解析透传，节点编辑「其他信息」同步支持
- REALITY / TLS 支持 ALPN 列表

## 下载测速改进

- **多节点并发测速**：同时测速节点数 1–6 可调（默认 3），
  节点多时成倍缩短总耗时；追求精确数值可选并发 1 逐个测试
- **延迟超时节点默认剔除**：测完延迟后，延迟超时的节点不再进入下载测速
  默认目标（手动多选仍尊重用户选择）；确认弹窗显示自动跳过数量，
  全部超时时直接提示无可测节点

## 测速可随时停止

- 测延迟 / 测下载进行中，按钮变为红色「停止」，点击即可中断后续批次；
  请求后按钮显示灰色「停止中」，当前批次（测延迟 16 并发 / 测下载按并发数）
  完成后停止
- 已测结果保留，未测节点回退为未测状态；中断停止不弹排序询问框

## Xray 内核更新至 v26.11.9

- vendored xray-core 由 v26.10.31 升级到 **v26.11.9**，
  `libxray.a` 已用新版内核重新构建
