# v2rayH 0.3.0

## 双内核：sing-box 加入（重点）

- **引入 sing-box v1.14.4 内核**，与 Xray 合并进同一个 `libxray.a`，
  单 App、单一 Go runtime，安装包结构不变
- **链式架构**：Xray 永远接管 tun 与路由；
  hy2 / tuic 等协议由 sing-box 经本机 socks 链式转发承载：

  ```
  tun ──► Xray ──► socks(127.0.0.1:10810) ──► sing-box ──► Hysteria2/TUIC ──► 互联网
  ```

- Xray 系节点（vless / vmess / trojan / ss）路径完全不变，零回归

## 新协议

- **Hysteria2**（`hy2://` 与 `hysteria2://` 分享链接解析与分享）：
  支持 sni / insecure / salamander 混淆 / alpn / 端口跳跃（mport）
- **TUIC**（`tuic://`）：uuid+password、sni、alpn，拥塞控制 bbr

## 内核自选

- 每节点可在「编辑节点」中选择运行内核：**自动 / Xray / sing-box**
  （hy2、tuic 始终由 sing-box 承载，其余协议可手动指定）
- 节点列表与配置页为 sing-box 系节点显示 `SB` 徽标
- 设置页「关于」显示双内核版本（Xray v1.261029.0 / sing-box v1.14.4）

## 测速与故障转移

- sing-box 系节点延迟测试走完整链式 HTTP 往返（UDP 端口 TCP ping 无意义），
  Xray 系节点保持 TCP Ping 并行
- 下载测速、故障转移探活同步适配双内核链路

## 下载与备份体验

- **资源文件与订阅更新默认走代理下载**：VPN 已连接时，
  geosite / geoip 更新与订阅拉取经本机代理（127.0.0.1:10809）发出，
  境外资源不再直连超时；未连接时提示后直连
- 备份还原、本地快照还原、清空节点等危险操作增加**确认弹窗**，
  完成后以气泡提示结果
- 修复旧版本（0.2.x）持久化数据在编辑节点时可能闪退的问题
