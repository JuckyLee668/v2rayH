## 安装

Release 里的 HAP **未签名**，无法直接安装。签名绑定开发者证书和设备，所以按社区惯例
（ClashBox 同样）只发未签名包，由使用者自行签名。

1. 用你自己的证书给 `v2rayH-0.2.2-unsigned.hap` 签名
   （DevEco Studio 的「自动生成签名」，或用 `hap-sign-tool`）。
2. 安装：`hdc install v2rayH-0.2.2-signed.hap`
3. 首次连接时在系统弹窗里授予 VPN 权限。

校验下载：

```
sha256sum -c v2rayH-0.2.2.sha256
```

## 这个版本改了什么

**最低系统要求提升至 HarmonyOS 6.1**
- `compatibleSdkVersion` 升到 `6.1.0(23)`，需要 HarmonyOS 6.1 及以上

**底部页签沉浸光感**
- 底部导航改用 `HdsTabs` 悬浮样式，通过 `barFloatingStyle.systemMaterialEffect`
  开启沉浸光感材质（`ADAPTIVE` 类型 + `ADAPTIVE` 等级，随设备算力自适应）
- 移除旧的整条底栏背景色 + 毛玻璃实现，避免遮挡材质效果

**订阅分组更新**
- 新增按分组拉取订阅（`updateGroupSubscription`），每组独立更新并显示状态
- 首页节点计数旁新增刷新按钮，点击更新当前分组
- 更新失败时给出具体原因（订阅链接为空 / 拉取失败 / 解析失败）

**剪贴板导入**
- 导入前动态申请 `ohos.permission.READ_PASTEBOARD` 权限（含权限说明文案）
- 读取剪贴板的各类失败场景（空剪贴板 / 非文本 / 读取异常）均有明确提示

## 已知限制

- 分应用代理未实现：鸿蒙不支持三方应用枚举已安装应用，也没有系统级应用选择器
- 沉浸光感材质依赖设备算力，低端设备由系统自动降级显示
- 上架 AppGallery 需要 release 证书签名，本包用的是本地调试签名
