## 安装

Release 里的 HAP **未签名**，无法直接安装。签名绑定开发者证书和设备，所以按社区惯例
（ClashBox 同样）只发未签名包，由使用者自行签名。

1. 用你自己的证书给 `v2rayH-0.2.0-unsigned.hap` 签名
   （DevEco Studio 的「自动生成签名」，或用 `hap-sign-tool`）。
2. 安装：`hdc install v2rayH-0.2.0-signed.hap`
3. 首次连接时在系统弹窗里授予 VPN 权限。

校验下载：

```
sha256sum -c v2rayH-0.2.0.sha256
```

## 这个版本改了什么

界面重整为三个页签（主页 / 配置 / 设置），底部是沉浸光感的悬浮导航。

**主页**
- 上部订阅节点列表，可下拉切换订阅分组，选中节点后点底部按钮连接
- 右上角状态胶囊下显示代理出口 IP（连接后自动获取）
- 已连接时点另一个节点会直接热切换并重新取 IP，不用手动断开

**配置**
- 订阅分组：新建 / 切换 / 删除，分组独立保存，更新订阅只覆盖当前分组
- 订阅入口：扫码导入、剪贴板导入、手动添加（VLESS / VMess / Trojan / Shadowsocks，
  可选 TCP / WebSocket / gRPC，TLS / REALITY）
- 本机导入的节点统一进入「本机节点」分组，不会被更新订阅冲掉
- 路由设置：CN 直连、广告拦截、自定义直连域名与强制代理域名
- 资源文件：常见 geo 来源一键切换、剪贴板粘贴直链、本地 .dat 导入，
  资源列表显示文件名 / 大小 / 更新时间，带「立即更新」

**设置**
- 外观：深色模式（跟随系统 / 浅色 / 深色）+ 五种主题色，即时生效
- 备份与还原：导出 / 导入 JSON，另有本地快照可还原
- 关于：应用版本、libxray 内核与 xray-core 版本

**优化**
- 去掉后台常驻长任务，退到后台后由系统正常冻结 UI 进程（VPN 扩展照常工作）
- 关闭 Xray 访问日志、日志级别降到 error，减少空闲期写盘

## 已知限制

- 分应用代理未实现：鸿蒙不支持三方应用枚举已安装应用，也没有系统级应用选择器
- 内核版本 `v1.260327.0` 在编译期写入，升级 libxray 时需同步
- 上架 AppGallery 需要 release 证书签名，本包用的是本地调试签名
