## 安装

Release 里的 HAP **未签名**，无法直接安装。签名绑定开发者证书和设备，所以按社区惯例
（ClashBox 同样）只发未签名包，由使用者自行签名。

1. 用你自己的证书给 `v2rayH-0.1.0-unsigned.hap` 签名
   （DevEco Studio 的「自动生成签名」，或用 `hap-sign-tool`）。
2. 安装：`hdc install v2rayH-0.1.0-signed.hap`
3. 首次连接时在系统弹窗里授予 VPN 权限。

校验下载：

```
sha256sum -c v2rayH-0.1.0.sha256
```

## 这个包是什么

HarmonyOS / OpenHarmony 上的 VLESS / VMess / Trojan / Shadowsocks 客户端，内核是
[Xray-core](https://github.com/xtls/xray-core)。流量路径：

```
应用 ──► vpn-tun (VpnExtensionAbility) ──► gVisor netstack (L3→L4)
     ──► Xray VLESS+REALITY 出站 ──► 外网
```

已支持：订阅解析、服务器列表、真实延迟测试、geoip/geosite 分流（cn 直连、其余走代理）。
