## 安装

Release 里的 HAP **未签名**，无法直接安装。签名绑定开发者证书和设备，所以按社区惯例
（ClashBox 同样）只发未签名包，由使用者自行签名。

1. 用你自己的证书给 `v2rayH-0.2.1-unsigned.hap` 签名
   （DevEco Studio 的「自动生成签名」，或用 `hap-sign-tool`）。
2. 安装：`hdc install v2rayH-0.2.1-signed.hap`
3. 首次连接时在系统弹窗里授予 VPN 权限。

校验下载：

```
sha256sum -c v2rayH-0.2.1.sha256
```

## 这个版本改了什么

**鸿蒙 6.0+ 兼容**
- `compatibleSdkVersion` 降到 `6.0.0(20)`，HarmonyOS 6.0 及以上可安装
- 移除 API 26 专属的沉浸光感 tabBar 与 `Circle.fill`，改用 6.0 可用的实现
- `protectProcessNet`（API 22+）在 6.0 上自动跳过，仍通过 `blockedApplications` 防止路由回环

**首页测速**
- 新增「节点测速」卡片：延迟测速（全部节点）+ 下载测速（当前选中节点）
- 下载测速默认使用 Cloudflare 20MB HTTP 测速文件，失败回退 CacheFly 10MB
- 结果同时显示 Mbps 与 MB/s；测速通过临时 Xray 实例走当前节点，不影响已建立的 VPN

**CI / 发布**
- GitHub Actions 使用 `devecocli` + 华为 Command Line Tools 直接构建未签名 HAP
- CLT 超过 2GB 时支持分卷上传，workflow 自动合并
- 原生代码变化时默认从源码重建 `libxray`，确保下载测速接口与 App 一致

## 已知限制

- 分应用代理未实现：鸿蒙不支持三方应用枚举已安装应用，也没有系统级应用选择器
- 下载测速每次消耗约 20MB 流量；慢速节点会在超时后给出部分结果
- 内核版本 `v1.260327.0` 在编译期写入，升级 libxray 时需同步
- 上架 AppGallery 需要 release 证书签名，本包用的是本地调试签名
