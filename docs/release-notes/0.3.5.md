# v2rayH 0.3.5

## hy2 改由 Xray 原生承载

- Hysteria2 节点默认由 Xray 内核直接承载，不再经 sing-box 链式转发：
  流量路径少一跳本机回环与一层代理，连接 hy2 节点时 sing-box 进程不再启动，
  单进程运行更省电、内存占用更低
- 勾选「跳过证书校验」的 hy2 节点仍自动改用 sing-box 承载
  （新版 Xray 已移除 allowInsecure，跳证书校验只有 sing-box 支持）
- tuic / anytls 维持 sing-box 承载不变；每节点仍可手动指定运行内核
- 设置页、节点编辑、手动添加处的双内核说明文案同步更新

> 安装包为未签名 HAP，用「小白调试助手」或 DevEco Studio 自行签名安装，
> 见 README「安装」一节。系统要求 HarmonyOS 6.1 及以上。
