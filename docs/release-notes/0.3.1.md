# v2rayH 0.3.1

## 延迟测速改为真实连接延迟

- Xray 系节点（vless / vmess / trojan / ss）不再使用裸 TCP 握手计时，
  改为与 sing-box 系节点一致：经临时内核实例**通过节点代理**实测
  HTTP 往返（`http://www.gstatic.com/generate_204`）
- 以前「TCP 能通、但代理协议实际不通」的节点会显示一个偏小的假延迟，
  现在会正确显示为失败
- 数值整体比旧版偏大属正常 —— 包含协议握手与出口 HTTP 往返
- 并发结构不变：Xray 系每批 5 节点并发，sing-box 系串行

## 下载测速备用源更换

- 原备用源 cachefly（10MB）文件过小 —— 快速节点一秒内下完，
  测不出稳态速率；且可达性差
- 换为 OVH `proof.ovh.net` 100MB 测试文件：
  主源 Cloudflare 失败时，备用源同样能测出稳态速率

> 安装包为未签名 HAP，用「小白调试助手」或 DevEco Studio 自行签名安装，
> 见 README「安装」一节。系统要求 HarmonyOS 6.1 及以上。
