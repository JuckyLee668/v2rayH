# v2rayH 0.2.5

## 内核

- **Xray 内核升级至 v26.10.29**（含 v26.10.21 起的根证书安全修复）
- 移除 gVisor：新版内核自带轻量用户态 TCP/IP 栈，体积更小、路径更短

## 下载测速（重点修复）

- 修复测速结果只有真实带宽约五分之一的问题：改用 Speedtest 方法论 ——
  4 并发连接 + 预热段排除 TCP 慢启动 + 20 秒稳态计时段
- 测试数据量提升至每节点最多 100MB，点击时弹窗确认并提示流量消耗
- 支持**多选 / 全部分组节点批量测速**，逐个节点测试并显示进度
- 测速完成后可选择「按速率从高到低」排序节点

## 延迟测速

- TCP Ping 延迟测速，测速完成后可选择「按延迟从低到高」排序节点
- 节点列表同时展示延迟与速率：延迟在上、速率在下

## 其他

- 节点测速面板默认折叠，点击展开后才显示测速按钮与多选圈
- 故障转移：当前节点不可达时自动切换到下一个节点
- 分应用代理：全部应用 / 仅代理选中 / 排除选中
- 多选节点批量测速与操作；扫码 / 剪贴板 / 手动添加节点；节点分享

> 安装包为未签名 HAP，用「小白调试助手」或 DevEco Studio 自行签名安装，
> 见 README「安装」一节。系统要求 HarmonyOS 6.1 及以上。
