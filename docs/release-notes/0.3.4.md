# v2rayH 0.3.4

## IPv6 接管

- VPN 支持 IPv6：TUN 分配 inet6 地址并接管 v6 流量，v6 请求经节点转发，
  杜绝 v6 直连泄漏

## 内置 DNS 模块

- 新增应用级 DNS：DoH（1.1.1.1 / 8.8.8.8）+ 域名嗅探 + 53 端口 DNS 劫持，
  解析结果由代理内核统一调度，避免系统 DNS 污染
- fallback DNS 使用 223.5.5.5 纯 UDP 直连（附 direct 路由规则），
  修复 DoH 全部经节点不可达时解析卡死；8.8.8.8 DoH 冗余
- 分流设置变更后自动应用并重连 VPN，无需手动断开重连

## 订阅流量信息

- 订阅分组显示 `subscription-userinfo` 流量信息：
  已用 / 总量、剩余、到期时间与用量进度条（超 90% 变红、过期标红）
- 支持超大流量面板（TB 级不限量套餐）格式化显示
- 修复订阅更新后分组列表不刷新（ForEach 键值未含变化字段）

## VPN 扩展心跳看门狗

- 扩展每 10 秒写入心跳文件，主进程看门狗检测心跳超时
  （35 秒阈值、2 次确认、启动 30 秒宽限期）后自动重启扩展并恢复
  流量会话，失败时如实显示断开状态
- 修复扩展被系统终止后 UI 长期假显示「已连接」、流量裸奔的问题
- 应用启动时若扩展仍在运行（心跳新鲜）则直接恢复已连接状态

## 测延迟体验优化

- 测延迟结果完成一个显示一个，不再等待整批 16 个节点全部结束
- 新增「设置 → 测速 → 延迟测试超时」（3–30 秒，默认 10），
  超时越短总耗时越短，但弱节点可能被误判超时；设置持久化保存

> 安装包为未签名 HAP，用「小白调试助手」或 DevEco Studio 自行签名安装，
> 见 README「安装」一节。系统要求 HarmonyOS 6.1 及以上。
